# primitives-conformance

Language-neutral test vectors that every `primitives-*` port runs, so five implementations
of the same idea cannot quietly disagree about what it means.

A vector is a frozen `(operation, input, expected output)` triple in JSON. It is not a test
framework, a runner, or a dependency — it is data. Each port reads these files in whatever
its own test framework already is.

## Why this exists

**A name is not a contract.** Four repositories can ship a package called `identifiers` and
mean four different things by it, and nothing will tell you until a client's ID is rejected
by a server in production.

That is not hypothetical. Writing the first vectors turned it up immediately:

| port | scheme | length | accepted by `primitives-go`'s `Validate`? |
| --- | --- | --- | --- |
| `primitives-go` | xid (`rs/xid`) | 20 | ✅ — it is the definition |
| `primitives-swift` | xid (`XID.swift`) | 20 | ✅ |
| `primitives-kt` | ULID (Crockford) | 26 | ❌ |
| `primitives-ts` | nanoid (`urlAlphabet`) | 21 | ❌ |

The resolution was not to converge four implementations. It was to notice that **a client
has no business generating a server's identifiers at all** — the server issues them, the
client receives opaque strings, and validating an ID the server just sent you proves
nothing. So `identifiers` is a `primitives-go` package, it has no vectors, and the three
non-Go ports drop it.

That is the suite working. Its first act was to delete a package rather than to test one.

## Scope

A package belongs here when its behaviour is **deterministic** — same input, same output,
in any language. That excludes anything whose answer depends on a clock, a network, a
random source or an ambient environment.

**The suite tests the overlap; it does not define the surface.** Each port carries only what
its consumers need. A vector file obligates exactly the ports its roster in `manifest.json`
names: a named port implements the package and passes every case, and a port the roster does
not name skips the file without failing. Putting a port on a roster is the decision that it
carries the package. See [SCHEMA.md](SCHEMA.md#manifest) for the roster and what a runner
does with it.

`primitives-go` is the source of truth for behaviour, since the vectors are generated by
observing it and never by hand. So it is on every roster, and a package enters the suite only
once it exists there: a package another port has and `primitives-go` does not is out of scope.

## What is in v1

| package | cases | what it pins |
| --- | --- | --- |
| `bitmask` | 18 | flag-set algebra: set, clear, toggle, has/all/any, count |
| `numbers` | 11 | decimal rounding and scaling at 32-bit float precision |
| `errors` | 20 | every error code's HTTP status, both directions |
| `retry` | 5 | the exponential backoff schedule, jitter off |
| `encoding` | 4 | decoding JSON/YAML/XML/TOML to one canonical value |

Every v1 file names all four ports: `primitives-go`, `primitives-kt`, `primitives-swift` and
`primitives-ts`.

58 cases, run in CI against a live `primitives-go` checkout by
[`generator/verify_test.go`](generator/verify_test.go) — the reference runner, and the shape a
port's own runner should copy. See [SCHEMA.md](SCHEMA.md) for the file format.

## Consuming this

Ports **vendor** a copy rather than fetching at test time, so the suite runs offline with no
auth and no submodule:

```
primitives-ts/
  testdata/conformance/
    VERSION         # v1
    manifest.json
    vectors/*.json
```

Copy `VERSION`, `manifest.json` and `vectors/` into the port, then run
[`tools/verify-pin.sh`](tools/verify-pin.sh) from CI. It compares the vendored pin against
the newest tag here and fails when the port is behind — so drift is a red build rather than
a silent divergence.

## Adding vectors

Vectors are **generated from `primitives-go`, never written by hand.** A hand-written
expectation is a guess about behaviour; a generated one is a recording of it. The generator
imports the real packages and writes what they actually do.

When a vector changes, that is a behaviour change in the shared surface: bump `VERSION`, tag
it, and every port's drift check goes red until it catches up. That is the point.
